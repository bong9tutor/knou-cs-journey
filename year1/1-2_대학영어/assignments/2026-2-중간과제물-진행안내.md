# 2026학년도 2학기 대학영어 중간과제물 진행 안내

> **목표:** 아래 순서대로 A와 B를 모두 작성하고 제출한다. A와 B는 각각 15점으로 총 30점이다.
> **정시 제출 마감:** 2026년 10월 12일 월요일 18:00. 권장 제출일은 10월 11일이다.
> **용도:** 과제 준비와 진행 상황을 관리하는 개인용 안내서. 실제 제출 답안은 별도의 한글 또는 Word 문서로 작성한다.
> 작성 기준일: 2026년 10월 4일.

## 1 먼저 해야 할 일을 한눈에 확인하기

| 구분 | 학교가 요구하는 작업 | 완료 기준 |
|---|---|---|
| A | 교재 Unit 1과 멀티강의 1·2강의 모든 문장에서 타동사가 쓰인 문장을 찾아 문장별로 타동사와 목적어 제시 | 해당 문장 전부 검토, 번호 부여, 타동사와 목적어 정리 |
| B의 교재 정리 | 교재 Part 2의 Unit 9·10에서 키워드 10개 선정, 각 키워드의 정의 또는 관련 설명을 교재에서 찾아 적고 한글 해석 | 10개 모두 교재 원문·해석·교재 쪽수 기재 |
| B의 외부 자료 | 각 키워드마다 2026년도 교재 외 자료에서 영어 예문 2개를 찾아 적고 한글 해석 | 총 20개 예문과 해석, 예문 속 키워드 밑줄, 정확한 출처·연도 표시 |
| B의 수행 소감 | 과제수행에서 어려웠던 점 서술 | 전체 수행에 대한 5줄 작성 |

**학교 지시와 이 문서의 권장 방법을 구분한다.** 과제 범위·개수·표시 항목은 학교 지시다. 아래 일정, 작업 메모, 파일명, 문서 구성은 실행하기 편하게 만든 권장안이다.

**생성형 AI 관련 지시:** 원본 PDF 1쪽의 A 작성 지시사항에는 “생성형AI를 사용하지 않는다.”가 명시되어 있다. A의 문장 선정과 분석은 직접 수행한다. B에 대한 별도 허용 문구는 없으므로, 이를 허용으로 단정하지 않는다. 이 안내서와 기존 요약 노트는 제출 답안으로 복사하지 않고 준비·복습에 사용한다.

## 2 교재와 기존 자료 준비하기

### 2단계에서 할 일

- [ ] 과제 안내 PDF의 1쪽과 2쪽을 모두 읽는다.
- [ ] 현재 수강 교재의 **Unit 1 전체**와 **Part 2 Unit 9·10**을 펼칠 수 있게 준비한다.
- [ ] 멀티강의 1·2강 영상과 강의록을 준비한다.
- [ ] 교재 쪽수를 적을 수 있도록 인쇄된 쪽수 또는 전자교재의 실제 교재 쪽수를 확인한다.
- [ ] 교재와 강의록에서 검토한 위치를 기록할 작업 메모를 만든다.

### 기존 자료를 활용하는 순서

아래 학습노트 링크로 HTML 학습 화면을 열 수 있다. 강의록 원본과 멀티강의는 수강 계정에서 확인한다. 요약 노트로 흐름을 이해한 뒤, 실제 답안의 문장·범위·쪽수는 교재와 강의 원문에서 확인한다.

| 자료 | 이번 과제에서의 쓰임 | 확인할 점 |

**범위 주의:** B의 범위는 **교재 Unit 9·10**이다. 기존 9·10강 노트만으로 범위를 대체하지 말고 교재 Unit 10도 직접 확인한다. 교재의 정의·설명과 쪽수는 강의록이나 노트의 쉬운 풀이로 대신하지 않는다.

기존 기출문제와 생성 모의고사는 시험 대비 자료다. 이번 중간과제물의 문제나 제출 항목으로 사용하지 않는다.

**완료 기준:** A와 B의 원자료를 모두 확보하고, 어떤 자료를 어디에 사용할지 구분했다.

## 3 실제 제출용 문서 틀 만들기

1. 한글 또는 Word에서 새 문서를 만든다. 안내문에 명시된 형식은 **hwp, hwpx, doc, docx**이다.
2. 본문을 **A 타동사와 목적어 정리 → B 키워드 10개 정리 → 과제수행에서 어려웠던 점** 순서로 구분한다.
3. 표지·학번·이름 등은 학교 서식과 제출 화면의 요구에 맞춰 넣는다.
4. 파일을 저장한다. 예시 파일명은 `2026-2_대학영어_중간과제물_이름.docx`이며 학교 지정 파일명은 아니다.
5. 원문 위치, 검토 여부, 애매한 문장을 적는 **작업 메모**는 제출 본문과 구분한다.

학교는 A의 성격상 분량·글자 크기·줄 간격을 따로 정하지 않았다. 임의의 페이지 수에 맞추려고 해당 문장을 줄이지 않는다. B의 키워드·예문 개수와 어려웠던 점 5줄은 지킨다.

**완료 기준:** 실제 답안을 입력할 수 있는 편집 문서와 별도의 작업 메모가 준비되었다.

## 4 A의 범위를 처음부터 끝까지 훑기

**학교 지시:** 교재 Unit 1과 멀티강의 1·2강에 제시된 **모든 문장**이 범위다. 본문에만 한정하지 않는다.

1. 기존 1·2강 노트로 본문 흐름과 문장 구조를 먼저 복습한다.
2. 교재 Unit 1을 처음부터 끝까지 읽으며 검토한 쪽을 표시한다.
3. 멀티강의 1강과 2강을 순서대로 확인한다. 강의록의 본문뿐 아니라 어휘 설명용 예문과 연습문제 등 문장이 제시된 부분도 검토한다.
4. 각 문장에서 동사와 분사로 쓰인 형태를 찾고, 타동사 사용 여부를 직접 판단한다.
5. 판단이 어려운 문장은 작업 메모에 위치와 질문을 적어 둔다. 전체 범위를 먼저 훑고 다시 검토한다.

| 검토 대상 | 시작 전 | 전체 검토 후 |
|---|---|---|
| 교재 Unit 1 전체 | [ ] | [ ] |
| 멀티강의 1강 전체 | [ ] | [ ] |
| 멀티강의 2강 전체 | [ ] | [ ] |

**완료 기준:** 세 범위를 모두 검토했고, 제출 대상 문장과 추가 확인할 문장을 구분했다. 학교가 문장 수를 지정하지 않았으므로 임의로 ‘몇 문장만’ 선정하지 않는다.

## 5 A의 문장별 답안 작성하고 재검토하기

### 각 문장을 처리하는 순서

1. 타동사가 사용된 문장 전체를 원문과 대조하여 적는다.
2. `문장1`, `문장2`처럼 번호를 붙인다.
3. 해당 문장의 타동사와 목적어를 짝지어 적는다. 한 문장에 여러 개가 있으면 빠짐없이 적는다.
4. **목적어는 핵심 단어 하나만** 적는다. 긴 명사구 전체를 그대로 쓰지 않는다.
5. **과거분사·현재분사·수동태에 사용된 경우도 포함**했는지 다시 살핀다.
6. 과제에서 제외한 **동사구**를 잘못 넣지 않았는지 확인한다. 안내문은 `respond to ~`, `feed on ~`를 제외 예로 든다.

### 입력 형식

아래 대괄호 부분을 직접 작성한 내용으로 바꾼다. 동사는 학교 예시처럼 원형으로 정리하는 방식이 좋다.

```text
문장1: [교재 또는 강의에 나온 문장 전체]
타동사와 목적어:
[타동사] - [목적어의 핵심 단어 하나]
[같은 문장에 추가로 있는 타동사] - [해당 목적어의 핵심 단어 하나]

문장2: [다음 해당 문장 전체]
타동사와 목적어:
[타동사] - [목적어의 핵심 단어 하나]
```

수동태와 분사 구문은 동사 바로 뒤에 목적어가 보이지 않을 수 있다. 동작과 그 대상의 관계를 확인하고 안내문 예시의 처리 방식을 따른다. 원문에 없는 목적어를 임의로 만들어 넣지 않는다.

**추가 확인이 필요한 경우:** 반복해서 등장하는 동일 문장의 제출 처리, 목적어가 여러 개인 구문의 표기, 연습문제의 빈칸·오류 문장 표기처럼 안내문이 세부적으로 정하지 않은 사항은 작업 메모에 남긴다. 원문·강의 설명으로도 해결되지 않으면 과목 질의응답에서 확인한다. 이 때문에 다른 문장 검토까지 멈출 필요는 없다.

**완료 기준:** 전체 범위 검토를 마쳤고, 문장 번호·타동사·핵심 목적어를 갖췄으며 분사와 수동태까지 재검토했다.

## 6 B의 키워드 10개 선정하고 교재 내용 정리하기

1. **교재 Part 2의 Unit 9·10**을 읽고 키워드 후보를 표시한다.
2. 키워드의 정의 또는 관련 설명이 교재 어디에 있는지 확인한다.
3. 2026년도 영어 자료에서도 해당 키워드를 찾을 수 있는지 먼저 살핀 후 **10개**를 확정한다.
4. 각 키워드의 **교재 정의 또는 관련 설명 원문**을 적는다.
5. 그 원문을 한글로 해석한다.
6. 정의·설명이 실린 **교재 쪽수**를 바로 적는다. 나중에 기억으로 채우지 않는다.

키워드 10개는 Unit 9·10의 범위에서 고른다. 안내문에 단원별 개수 배분은 따로 명시되어 있지 않다. 임의로 ‘각 Unit에서 반드시 5개씩’이라는 조건을 추가하지 않는다.

기존 9·10강 노트의 주요용어 표는 교재를 찾기 위한 보조 자료다. 노트에 등장한다는 이유만으로 과제 키워드에 해당한다고 확정하지 말고, 교재의 해당 내용과 대조한다.

**완료 기준:** 키워드 10개 각각에 교재 원문, 한글 해석, 교재 쪽수가 있다.

## 7 B의 2026년도 영어 예문 20개 수집하기

### 키워드 하나마다 반복할 작업

1. 선택한 키워드에 `2026`을 함께 넣어 뉴스·정보 자료 등을 검색한다.
2. 검색 결과 요약만 복사하지 말고 원문 페이지를 연다.
3. **자료가 2026년도 자료인지** 확인한다. 열람한 날짜나 사이트 맨 아래의 저작권 연도만으로 판단하지 않는다.
4. 해당 키워드가 들어간 영어 문장 2개를 찾는다. **인터넷 사전에서 가져온 예문은 제외**한다.
5. 각 문장을 정확히 옮기고 한글로 해석한다.
6. **예문 안에 있는 해당 키워드에 실제 밑줄**을 긋는다. 굵게 표시하거나 제목에만 밑줄을 넣는 것으로 대신하지 않는다.
7. 예문마다 정확한 원문 URL 또는 저서명을 적고, **2026년이라는 자료 연도도 별도로 명시**한다.

권장 검색 방식은 `"선택한 키워드" 2026`이다. 연도·발행일이 명확하고 원문을 직접 열 수 있는 자료부터 고르면 확인이 쉽다. 자료가 언제 작성되었는지 불명확하면 다른 자료를 찾는다.

학교는 키워드마다 예문 2개를 요구하지만 반드시 서로 다른 출처여야 한다는 조건은 안내문에 없다. 다만 각 예문의 출처와 연도가 분명하게 확인되어야 한다. 뉴스·웹 자료에는 제목·발행기관·발행일을, 저서에는 저자·출판사·발행연도·쪽수를 함께 적어 두면 재확인이 편하다. 이 추가 정보는 관리용 권장 사항이다.

### 키워드별로 반복해서 사용할 구성

```text
키워드 1: [영어 키워드]

1. 교재 정의 또는 관련 설명
영어 원문: [교재 내용]
한글 해석: [직접 작성]
교재 위치: Part 2, Unit [9 또는 10], p. [쪽수]

2. 외부 예문 1
영어 예문: [2026년도 원문 문장 / 키워드에 실제 밑줄]
한글 해석: [직접 작성]
출처: [정확한 원문 URL 또는 저서명]
자료 연도: 2026년
확인 메모: [발행일 또는 서지정보 / 권장]

3. 외부 예문 2
영어 예문: [2026년도 원문 문장 / 키워드에 실제 밑줄]
한글 해석: [직접 작성]
출처: [정확한 원문 URL 또는 저서명]
자료 연도: 2026년
확인 메모: [발행일 또는 서지정보 / 권장]
```

**완료 기준:** 10개 키워드 × 2개 = **20개 영어 예문**과 **20개 한글 해석**이 있고, 각 예문에 키워드 밑줄·출처·2026년 표시가 있다.

## 8 과제수행에서 어려웠던 점 5줄 쓰기

A와 B를 수행하며 실제로 어려웠던 점을 메모해 두었다가 B의 마지막에 5줄로 정리한다. 키워드마다 5줄씩 쓰는 요구가 아니라 과제수행에 대한 항목이다.

아래 질문을 바탕으로 자신의 경험을 작성한다. 질문 자체를 답안으로 제출하지 않는다.

1. 어떤 작업에서 가장 어려움을 느꼈는가?
2. 구체적으로 무엇을 판단하거나 찾기 어려웠는가?
3. 해결하려고 어떤 자료나 방법을 사용했는가?
4. 그 방법으로 무엇이 해결되었고 무엇이 남았는가?
5. 이번 경험을 통해 다음에는 어떻게 진행하려 하는가?

**완료 기준:** 자신의 수행 경험을 썼고, 최종 한글·Word 화면에서 5줄 분량인지 확인했다. 줄바꿈과 자동 줄바꿈 때문에 줄 수가 달라지지 않는지 살핀다.
